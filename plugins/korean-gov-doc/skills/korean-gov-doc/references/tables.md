# 표 조판

## pandoc 파이프 표 열 너비

pandoc은 구분선의 대시 개수를 상대 폭으로 읽는다. 다만 **구분선 전체 길이가 약 72자를 넘어야** 이 값이 반영된다. 짧으면 균등 분할된다.

```python
def W(*cols):
    """(폭, 정렬) 쌍으로 구분선 생성. 정렬 'l'=좌측, 'c'=가운데"""
    out = []
    for n, a in cols:
        out.append(":" + "-" * n + (":" if a == 'c' else ""))
    return "|" + "|".join(out) + "|"

# 예 : 단계 열은 좁고 가운데, 수행 내용은 넓고 좌측
W((6,'c'), (62,'l'), (28,'l'))
```

폭은 절대값이 아니라 비율이다. 합이 100이 되도록 잡으면 백분율처럼 읽을 수 있다.

## 정렬 기준

| 열 성격 | 정렬 | 예 |
|---|---|---|
| 순번·단계·No.·배점 | 가운데 | 1, 2, 3 / ①② |
| 단위·수치·기호 | 가운데 | ㎥, t, 【 】, ○, − |
| 항목명·구분 | 좌측 (짧으면 가운데) | 실행물량, 기준차이 |
| 설명·내용 | 좌측 | 문장이 들어가는 열 |

## 폭 배분 요령

- 값이 대부분 `【 】`인 열은 넓을 이유가 없다. 측정 항목명 열을 넓히는 편이 낫다.
- 헤더 텍스트가 두 줄로 깨지면 폭이 부족한 것이다. "대표기관 여부" → "대표기관"처럼 헤더를 줄이는 것도 방법.
- 긴 라벨(예 「기초 우마철근·받침철근 배치간격」)이 있는 열은 40% 이상 줘야 한 줄에 들어간다.
- 헤더에 괄호 설명을 넣으면 폭을 잡아먹는다. 설명은 셀 안으로 내린다.
  - 나쁨 : `안 A · 초기 기준 (현장 관행)`
  - 좋음 : 헤더 `안 A · 초기 기준` / 셀 `현장 관행 — 공사 착수 시점의 기준`

## 세로 병합 (pandoc 불가)

공고문 요약표처럼 라벨이 여러 행을 묶는 구조는 raw OOXML로 만든다. `assets/ooxml_form.py` 사용.

```python
rows = [
  tr([tc(G[0], para('기술요약', b=True, jc='center'), vmerge='restart', shade='D9D9D9'),
      tc(G[1], para('기술 개요', jc='center'), shade='F2F2F2'),
      tc(G[2], bullets(OVERVIEW))]),
  tr([tc(G[0], '', vmerge='cont', shade='D9D9D9'),      # 병합 계속 셀은 내용 비움
      tc(G[1], para('제안 특징점', jc='center'), shade='F2F2F2'),
      tc(G[2], bullets(FEATURES))]),
]
```

가로 병합은 `span=N` (gridSpan). 그리드 열 개수는 표 전체에서 하나이므로, 상단부와 하단부의 열 구성이 다르면 **표를 둘로 나누는 편이 간단하다.** 시각적으로는 붙어 보이므로 양식 준수에 문제없다.

## 페이지 경계

표가 페이지 끝에 걸려 머리행만 다음 장에 남거나 마지막 행 한 줄이 넘어가면:

1. **열 너비를 조정해 줄바꿈을 없앤다** — 가장 확실하다. 두세 줄만 줄여도 해결된다.
2. 표 앞의 그림 삽입 영역 높이를 조금 줄인다.
3. 그래도 안 되면 앞 절에 페이지 나눔을 넣는다.

Word와 LibreOffice의 페이지 계산이 다르므로, LibreOffice에서 딱 맞으면 Word에서 넘칠 수 있다. 여유를 두고 맞춘다.
