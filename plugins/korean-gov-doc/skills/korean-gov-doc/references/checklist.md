# 제출 전 점검

## 형식

- [ ] 공고문 목차(안)의 장·절 구성과 순서가 일치하는가
- [ ] 분량 제한을 지켰는가 (갑지·요약·목차·부록 제외한 본문 기준)
- [ ] 갑지·요약표가 공고문 원본 양식과 같은가 (라벨 문구, 항목, 열 구성)
- [ ] 공고문의 파란색 안내문(제출 시 삭제 대상)을 그대로 옮겨 놓지 않았는가
- [ ] 부록 중 "제출본에서 삭제" 표시된 것을 실제로 뺐는가

## 본문

- [ ] 계층이 □ / ○ / - 세 단계를 넘지 않는가
- [ ] 명사형 종결로 통일되었는가 ("~합니다" 잔존 여부)
- [ ] 들여쓰기가 전각공백(U+3000)인가
- [ ] 어려운 한자어를 풀어 썼는가
- [ ] 같은 개념에 두 가지 용어를 섞어 쓰지 않았는가 (예: 추적/탐지, 예산 초과/원가 초과)
- [ ] 상호 참조 절 번호가 실제 절 번호와 맞는가 — **절을 옮기거나 추가한 뒤 반드시 재확인**

## 수치와 근거

- [ ] `【 】` 잔존 항목을 모두 확인했는가 (의도적으로 남긴 것과 빠뜨린 것 구분)
- [ ] 수행 전 결과표에 "기재 양식(예시)" 표기가 있는가
- [ ] 인용 수치의 출처를 밝혔는가, 표기값과 항목 합계가 맞는가
- [ ] 실측하지 않은 값을 실측인 것처럼 쓰지 않았는가

## 그림

- [ ] 그림 번호가 읽는 순서대로 오름차순인가
- [ ] 본문 참조 번호와 캡션 번호가 일치하는가
- [ ] 캡처에 개인정보·타 현장명·파일 경로가 남아 있지 않은가
- [ ] 삽입 영역만 잡아 둔 그림을 실제 이미지로 채웠는가
- [ ] 익명 처리 대상은 원본 캡처가 아니라 재작도했는가

- [ ] 표가 페이지 경계에서 머리행만 남거나 한 행만 넘어가지 않는가
- [ ] 양식표가 한 페이지 안에 들어가는가 (Word 기준)
- [ ] 표 테두리가 모두 보이는가
